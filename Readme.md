# Yet another PIM (YAP)

Yet another PIM (YAP) is a Product Information Management system built with Symfony.

## About

- **Website:** https://yet-another-pim.eu
- **Wiki:** https://github.com/yetAnotherPim/yap/wiki
- **API documentation:** https://yet-another-pim.eu/api-docs/index.html

## Requirements

- **PHP 8.4 or higher** (PHP 8.5 recommended)
- **Composer**
- **PostgreSQL 16 or higher** (recommended database)

MySQL and MariaDB compatibility is currently under evaluation.

## Setup

See the [Setup Guide](https://github.com/yetAnotherPim/yap/wiki/Setup) for installation and configuration instructions.
